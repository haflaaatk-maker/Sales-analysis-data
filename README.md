# 📊 Sales Performance Dashboard – Excel

## 📌 Project Overview

The **Sales Performance Dashboard** is an interactive Excel-based data analytics project designed to analyze sales performance across different **salespersons, regions, products, quantities, prices, and time periods**.

The project transforms raw sales transaction data into meaningful business insights using **Excel Pivot Tables, charts, KPIs, and an interactive dashboard**.

This dashboard helps businesses quickly understand sales trends, identify top-performing products and salespeople, compare regional performance, and monitor overall revenue.

---

## 🎯 Project Objectives

* Analyze overall sales performance.
* Track sales trends over time.
* Compare sales performance across different regions.
* Identify the best-performing products.
* Analyze individual salesperson performance.
* Understand sales quantity and revenue patterns.
* Create an interactive and visually appealing Excel dashboard.
* Convert raw sales data into actionable business insights.

---

## 📂 Dataset

The project contains sales transaction data with **366+ records** and the following fields:

| Column   | Description                   |
| -------- | ----------------------------- |
| S No     | Unique transaction number     |
| Date     | Date of the sales transaction |
| Salesman | Name of the salesperson       |
| Region   | Sales region                  |
| Item     | Product sold                  |
| Qty      | Quantity sold                 |
| Price    | Unit price of the product     |
| Amount   | Total sales amount            |

**Amount = Quantity × Price**

## 📈 Dashboard Analysis

The dashboard provides analysis across several important dimensions:

### 🗓️ Monthly Sales Performance

Analyzes sales revenue by month to identify sales trends and high-performing periods.

### 🌍 Regional Performance

Compares sales across regions such as East, West, North, and South to identify the strongest markets.

### 🛍️ Product Performance

Analyzes revenue generated by individual products and helps identify the most profitable/highest-selling products.

### 👨‍💼 Salesman Performance

Compares salespersons based on their total sales contribution and identifies top performers.

### 📦 Quantity Analysis

Examines the quantity of products sold to understand product demand.
